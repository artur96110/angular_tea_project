# Контрольная №22 — чайный проект на Angular

## Запуск

```bash
npm install
npm start
```

После запуска открыть: `http://localhost:4200/`

## Что реализовано

- Angular-проект с роутингом.
- Страницы: Главная, Каталог, Страница товара, Оформление заказа.
- Меню содержит только «Главная» и «Каталог».
- Bootstrap подключен через `angular.json` в секциях `styles` и `scripts`.
- На главной странице есть баннер, FAQ и попап через `Observable`/`timer` через 10 секунд.
- Если уйти с главной раньше 10 секунд, попап не появляется: используется `takeUntil` в `ngOnDestroy`.
- Каталог получает товары GET-запросом с `https://testologia.ru/tea`.
- Страница товара открывается по кнопке «Подробнее».
- Кнопка «Купить» переносит на страницу заказа и передает выбранный товар в disabled-поле «Товар».
- Форма заказа реактивная, с валидацией по ТЗ.
- Отправка заказа идет POST-запросом на `https://testologia.ru/order-tea`.
- При `success: 1` форма скрывается и выводится «Спасибо за заказ!».
- При ошибке текст ошибки показывается на 3 секунды.
- Во время отправки кнопка disabled и показывается маленький loader.
- В каталоге есть loader.
- Реализован поиск по товарам через `BehaviorSubject`.
